# Smart India Hackathon (SIH 2025) Front-End Platform

[![Hackathon](https://img.shields.io/badge/Hackathon-SIH--2025-blue)](https://sih.gov.in/)

A structural, responsive front-end user interface built for the **Smart India Hackathon (SIH) 2025**. This repository contains the pure layout design, UI components, and aesthetic presentation grids optimized for rapid web rendering without heavy framework overhead.

🔗 **Live Link:** [sih-2025-livid.vercel.app](https://sih-2025-livid.vercel.app/)

---

## ✨ Key Design Features

- **Semantic UI Layout:** Crafted using standard, clean HTML5 components for accessible structural indexing.
- **Pure CSS Styling:** Responsive grid patterns, customized layout themes, and custom element design without depending on heavy third-party UI toolkits.
- **Cross-Device Fluidity:** Seamless, fluid adjustments to ensure the dashboard looks sharp on mobile viewports, tablets, and desktops alike.
- **Instant Core Web Vitals:** Lightweight structure translates to zero execution delays and incredibly fast load times.

## 🛠️ Built With

- **HTML5:** Core platform layout and dashboard structural forms.
- **CSS3:** Flexbox/Grid systems, responsive breakpoints, navigation blocks, and visual styling.
- **Vercel:** Cloud hosting deployment network.

## 🚀 Launching the Project Locally
Because this platform uses pure browser-native languages, you do not need to install complex dependencies or node modules to review it.

Step-by-Step

1. **Clone down this repository:**
```Bash
git clone [https://github.com/Tanushka-lokegaonkar/SIH2025.git](https://github.com/Tanushka-lokegaonkar/SIH2025.git)
cd SIH2025
```

2. **Open the platform:**

Double-click the index.html file inside your explorer view to open it instantly in any modern web browser (Chrome, Edge, Safari, Firefox).

Alternatively, use the Live Server extension in VS Code to see styling edits update instantly on your screen.

## 🌐 Automatic Deployment
Every time updates are pushed directly to the main branch, Vercel processes the changes and updates the production environment at sih-2025-livid.vercel.app within seconds.
